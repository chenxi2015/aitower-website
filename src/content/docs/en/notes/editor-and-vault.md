The Notes workspace is built for long-form writing and knowledge synthesis while operating directly on your local vault directory.

## Vault Tree & Safe File Operations

- **Filter by filename**: Type in the top search bar of the left tree to quickly locate notes and boards.
- **Create & organize**: Create notes or folders, refresh the tree, and adjust sorting directly in place.
- **Trash protection**: Deleting a file moves it to the system trash instead of permanently erasing it.

## Editor Modes

Powered by **CodeMirror 6**, you can switch between three viewing modes from the note header:

- **Live Preview**: Clean rendered formatting that reveals raw Markdown syntax on the active cursor line.
- **Source**: Plain Markdown source editing for precise structural control.
- **Read**: Distraction-free read-only mode for reviewing finished drafts.

## Native Ecosystem Compatibility

- **Wikilink completion**: Type `[[` to autocomplete notes, boards, and media assets in your vault.
- **Unified format support**: Open `.md`, `.canvas`, and `.excalidraw` files from the same tree without leaving aitower.
- **Cross-structure retrieval**: Search and AI retrieval cut through backlinks and `.canvas` files to surface related ideas while you write.
