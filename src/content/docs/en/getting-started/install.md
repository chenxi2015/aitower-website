## Supported Platforms

| Platform | Package Notes |
| :--- | :--- |
| **macOS** | Apple Silicon (`arm64`) and Intel (`x64`) |
| **Windows** | Windows `x64` installer |
| **Linux** | Linux `x64` packages |

Visit the [Download page](/en/download) for automatic platform detection, or browse all builds and checksums on [aitower-releases](https://github.com/chenxi2015/aitower-releases/releases/latest).

## Auto-Updates

The desktop app includes a built-in self-updater so you can stay current without manual reinstalls.
