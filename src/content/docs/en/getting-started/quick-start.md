## 1. Point aitower at Your Vault

Open aitower and select your local Obsidian vault directory. Your existing folder layout stays untouched, and deletions always go to the system trash.

## 2. Explore the Three-Pane Workbench

![aitower three-pane workbench layout](/docs/workbench-layout-en.svg)

- **Left Sidebar / Drawer**: Browse your vault tree in Notes mode, or switch between Boards, Frames, Templates, Asset Library, Image Toolbox, and Agent Skills in Studio mode.
- **Center Canvas**: Switch seamlessly between Notes and Studio in one window.
- **Right Agent Panel**: Context-aware AI assistant with concurrent sessions that never cross-talk.

## 3. Run the Illustration Loop

1. Open a Markdown note in the Notes workspace.
2. Ask the side-panel Agent to illustrate a section (for example, *"Sketch a hand-drawn system architecture for this section"*).
3. Refine the drafted nodes and arrows directly on the Studio board.
4. Export and insert — a crisp PNG/SVG is saved into your vault assets folder and `![[figure.png]]` lands right at your cursor.
