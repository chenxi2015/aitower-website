General-purpose prompts get verbose fast when you repeat specialized workflows. **Agent Skills** package proven instructions and tool conventions into reusable modules you can load on demand.

## Skill Sources & Management

Open **Agent Skills** in the Studio dock to browse, search, and filter installed skills by source:

- **All / Built-in**: Ready-to-use skills bundled with aitower.
- **Agents / Codex / Claude**: Unified management across common local skill directories.

Filter by name, description, or tags, and add new skills using **+ Install**.

## Example Skills

- `anatomy`: Explain technical concepts with detailed isometric SVG diagrams.
- `archify`: Create architecture, workflow, and data-flow visuals.
- `diagram-design`: Design cohesive charts, flows, and architecture diagrams.
- `article-to-video` / `baikou-style-video`: Turn long-form articles into narrated vertical videos.

## Loading Skills in Chat

Type `/` in the right-hand Agent composer to pick and attach one or more skills directly to your prompt.
