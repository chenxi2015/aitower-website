## Desktop App Shortcuts & Triggers

| Trigger | Scope | Action |
| :--- | :--- | :--- |
| `⌘N` | Notes workspace | Create a new note |
| `⌘O` | Notes workspace | Open a local file |
| `[[` | Markdown editor | Trigger Wikilink autocomplete across vault notes and boards |
| `/` | AI Agent composer | Load one or more specialized Agent Skills into the prompt |

> On Windows and Linux, use `Ctrl` in place of `⌘`.

## View & Canvas Controls

- **Editor view toggle**: Switch between **Live**, **Source**, and **Read** modes in the note header.
- **Aspect ratio toggle**: Switch between **Auto**, **3:4**, **9:16**, and **16:9** in the Studio top toolbar.
- **Canvas controls**: Zoom percentage, fit-to-screen, grid toggle, canvas lock, and undo/redo live in the bottom bar.

## Docs Website Shortcut

- `⌘K` (or `Ctrl+K`): Open the documentation search dialog with keyboard navigation.
