## 桌面客户端常用快捷键与触发词

| 触发方式 | 作用域 | 说明 |
| :--- | :--- | :--- |
| `⌘N` | 笔记工作台 | 新建笔记 |
| `⌘O` | 笔记工作台 | 打开本地文件 |
| `[[` | Markdown 编辑器 | 触发 Wikilink 双链补全，关联 Vault 内笔记与画板 |
| `/` | AI Agent 输入框 | 唤出技能列表，为当前对话载入一个或多个专属技能 |

> Windows / Linux 环境下，`⌘` 对应 `Ctrl` 键。

## 视图与画板操作提示

- **编辑视图切换**：文章标题栏右侧可在「实时预览 / 源码 / 阅读」三种模式间一键切换。
- **画板比例切换**：创作台顶部工具栏提供「自适应 / 3:4 / 9:16 / 16:9」快速切换。
- **画布缩放与撤销**：画布底部栏集中提供缩放比例、居中适配、网格显示、画布锁定与撤销/重做控制。

## 本文档站快捷操作

- `⌘K`（或 `Ctrl+K`）：打开使用文档全文搜索面板，支持方向键选择与回车跳转。
