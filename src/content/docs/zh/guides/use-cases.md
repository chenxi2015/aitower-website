以下三条路径展示了如何把「笔记工作台 + 创作画板 + 嵌入式 Agent」串联到日常高频创作中。

## 场景一：技术深度长文与架构复盘

1. **汇集材料**：在笔记工作台打开事故复盘、系统设计笔记或 `.canvas` 草稿，让 Agent 跨笔记提炼核心矛盾与反直觉观点。
2. **分段起草配图**：写到核心架构（如「请求 → 重试 → 幂等网关」）时，让 Agent 在创作台起草手绘流程图。
3. **半手搓精修与插入**：在画布上微调节点位置和便签配色，一键导出高清 PNG 插入光标处。

## 场景二：科研文献精读与概念图解

1. **论文笔记沉淀**：在 Vault 中用 Markdown + `[[双链]]` 记录多篇论文的核心方法与实验结论。
2. **对比矩阵生成**：通过 Agent 面板读取多篇论文笔记，直接整理出方案对比表格或研究演进脉络。
3. **逻辑外化**：借助创作台的思维导图 / 流程图模板将复杂机制画成一张图，附在文献笔记顶部方便日后回顾。

## 场景三：自媒体长图与知识卡片

1. **提炼金句与要点**：由长文草稿拆出结构化要点，借助 Agent 生成适合传播的对比视角。
2. **切换竖屏画幅**：在创作台顶部将比例切到 `3:4` 或 `9:16`，搭配便签、手绘图标与设备线框排版卡片。
3. **批量出图**：如需处理截图或统一尺寸，直接调用「图片工具箱」的公众号/小红书尺寸预设，导出后即可发布。
