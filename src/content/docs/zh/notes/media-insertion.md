传统写作软件配图通常需要「切到画图工具 → 导出图片到桌面 → 拖进附件目录 → 手写引用」，打断写作心流。aitower 把这一整段链路压缩成一个闭环动作。

## 从画板一键插入文章

1. **在创作台定稿**：完成架构图、流程图或信息卡片后，选择整块画板或指定框架（Frame）。
2. **导出到 Vault 资产目录**：aitower 自动导出高清 **PNG** 或 **SVG**（支持 2x 清晰度），直接保存到你的 Obsidian 资产目录中。
3. **光标处写入引用**：无需手动复制路径，系统会在文章当前光标处自动插入标准引用：

```markdown
![[重试流程图.png]]
```

## 拖拽图片与多格式混排

- **本地图片直拖**：可直接把本地图片或经过 [图片工具箱](/docs/studio/image-toolbox) 处理后的图片拖拽进文章排版。
- **实时预览**：在 CodeMirror 6 的实时预览模式下，插图与文字排版会同步呈现，方便随时检查图文节奏。
