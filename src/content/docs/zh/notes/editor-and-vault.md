笔记工作台面向深度长文写作与知识整理，所有读写直接作用于本地文件夹。

## 目录树与安全管理

- **按文件名快速过滤**：在左侧目录树顶部输入关键词即可实时筛选笔记与画板文件。
- **新建与整理**：支持快捷新建笔记、新建文件夹、刷新目录与排序。
- **回收站保护**：所有文件删除均通过系统回收站执行，避免误删不可逆。

## 编辑器模式

基于 **CodeMirror 6** 打造，支持三种阅读与编辑视图切换：

- **实时预览（Live Preview）**：所见即所得，光标所在行自动展开 Markdown 语法，其余区域保持干净排版。
- **源码模式（Source）**：纯文本 Markdown 视图，适合精细控制结构与批量编辑。
- **阅读模式（Read）**：只读排版视图，用于长文审阅与校对。

## 原生生态兼容

- **Wikilink 双链补全**：输入 `[[` 自动关联 Vault 内的笔记、画板与图片资产。
- **多格式互通**：在同一个目录树中直接打开 `.md`、`.canvas` 与 `.excalidraw` 文件，无需切换外部软件。
- **跨结构检索**：搜索与 Agent 检索可穿透双链与 `.canvas` 结构，帮助你在写作时快速把分散的卡片与笔记交叉归纳进正文。
