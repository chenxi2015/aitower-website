在 Obsidian 知识库积累到一定规模后，真正的难点不是「记下来」，而是在写新文章时把分散在不同文件夹里的概念重新串联起来。

## Wikilink 双链补全

在编辑器中输入 `[[` 后，aitower 会基于当前 Vault 目录实时联想可关联的笔记、画板与图片资产，避免手敲路径出错，保持与 Obsidian 完全一致的双链语法。

## 穿透 `.canvas` 与画板结构的检索

不同于只做纯文本匹配的搜索框，aitower 的检索与 AI Agent 读取链路能够穿透多种本地文件格式：

- **Markdown 笔记（`.md`）**：按文件名快速过滤或结合正文语义检索。
- **Obsidian 白板（`.canvas`）**：识别白板中的卡片与结构关系，方便交叉归纳。
- **手绘画板（`.excalidraw`）**：把画板里的图解资产同样纳入知识网络。

## 写作时如何配合 Agent 重组灵感

在写长文卡壳时，可以在右侧 Agent 面板直接发出跨目录指令，例如：

```text
结合「学习」和「自媒体」目录下的相关笔记，帮我提炼几个反直觉切入点。
```

Agent 会检索并读取相关笔记后，在对话流中展示操作步骤与结果，帮助你完成概念重组，再由你决定最终写入文章的结构。
