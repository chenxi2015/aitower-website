创作台（Studio）是一块专为技术架构图、流程图、知识卡片与信息图设计的手绘风无限画板。

## 画幅比例与画板管理

顶部工具栏提供常用比例快速切换，方便直接适配不同发布渠道：

- **自适应**：随画布内容自由延展，适合大型系统架构与头脑风暴。
- **3:4 / 9:16**：适合小红书、移动端长图或竖屏卡片排版。
- **16:9**：适合演示文稿、视频封面与横版文章插图。

在左侧功能停靠栏中，可以随时切换：

- **画板列表**：集中管理当前项目中的所有画板与框架（Frames）。
- **画板框架**：快速定位并导出画布中的特定局部区域。
- **画板模板**：支持本地与云端模板，一键起手头脑风暴或对比矩阵。

## 素材库（自有素材 / 官方素材）

左侧素材抽屉支持拖拽即用，分为两大来源：

- **官方素材**：预设架构组件、手绘图标、便签胶带、设备线框等，保持克制统一的手作质感。
- **自有素材**：收集并复用你平时沉淀的常用组件与图片资产，支持按「常用 / 组件 / 图片」过滤与搜索。

## 一键导出与插入

画板内容完成后，可直接导出高清 **PNG** 或 **SVG** 存入 Obsidian 资产目录，并将 Markdown 引用自动落回当前文章光标处。
