创作台左侧抽屉内置**素材库**与**画板模板**，让你既能保持统一的手作质感，又不必每次从零绘制基础图形。

## 素材库：自有素材 vs 官方素材

点击左侧停靠栏的「素材库」图标，可以在两个标签页之间切换：

- **官方素材**：内置手绘风格的架构组件、手绘图标、便签胶带与设备线框，开箱即用，直接拖拽到画布。
- **自有素材**：归集你自己沉淀的常用图形、组件与图片资产。顶部支持按 **常用 / 组件 / 图片** 分类筛选，并支持关键词搜索。

> 素材与画板均支持本地保存与状态同步，确保在不同文章之间可以持续复用同一套视觉语言。

## 画板模板（本地模板 / 官方云端）

在左侧停靠栏切换到「画板模板」，提供多种预设场景结构，适合快速开启特定思考任务：

| 模板名称 | 适用场景 |
| :--- | :--- |
| **头脑风暴** | 便签发散与观点聚合 |
| **思维导图** | 主题分支与知识网络梳理 |
| **任务看板** | 待办、进行中与完成状态追踪 |
| **用户旅程图** | 阶段体验拆解与痛点标注 |
| **流程图** | 步骤流转与条件分支示意 |
| **产品路线图** | 版本规划排期与时间线 |
| **空白画板** | 独立自由绘制 |

你也可以将自己打磨好的常用画板保存为「本地模板」，后续撰写系列长文时直接套用。
