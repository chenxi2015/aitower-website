文章配图和社媒卡片发布前，经常需要统一尺寸、压缩体积或清理背景。aitower 在创作台停靠栏中内置了**图片工具箱**，无需再额外打开网页端工具或修图软件。

## 支持的处理能力

| 工具 | 功能说明 | 常见用途 |
| :--- | :--- | :--- |
| **批量图片压缩** | 自由调节压缩质量与输出格式 | 控制长文与网页配图体积 |
| **批量修改尺寸** | 按比例缩放，内置公众号与小红书常用尺寸预设 | 快速适配多平台发布规格 |
| **批量图片裁剪** | 统一裁切为 `1:1`、`4:3`、`16:9` 或 `3:4` | 保持图文卡片视觉整齐 |
| **智能自动抠图** | AI 识别主体并剥离复杂背景 | 制作清爽透明底元素用于画板拼贴 |
| **图片变高清** | 针对模糊截图或低分辨率素材进行 `2x / 4x` 深度超分 | 提升老旧截图与参考图清晰度 |

## 使用流程

1. 在左侧停靠栏选择「图片工具箱」。
2. 从左侧列表选中需要的功能。
3. **导入图片**：直接拖拽本地 PNG / JPG / WebP 文件到工作区，或点击右上角「从笔记选择」直接挑选 Vault 内的图片。
4. 在右侧参数栏调整输出配置（如压缩质量、目标格式等），点击「开始批量处理」。
5. 处理完成后可直接存回 Obsidian 资产目录，立即用于文章或画板。
