传统 AI 生图往往直接输出一张不可修改的位图，文字错乱且难以贴合技术逻辑；aitower 采用**「AI 起草结构 + 手工微调细节」**的画板工作流。

## 三步配图闭环

### 1. 唤起配图
在撰写文章时点击「为本段配图」，或直接在右侧 Agent 面板中用自然语言描述需求（如*「把请求 → 重试 → 幂等网关的过程画成手绘架构图」*）。

### 2. 画板设计
Agent 会先读取相关笔记与上下文，随后在创作台自动生成分层合理的节点、连线箭头与便签说明。生成结果**完全可编辑**——你可以直接拖动位置、增删节点、替换素材库里的手绘图标或微调颜色。

### 3. 一键插入
确认画面后，执行导出插入即可将高清 PNG/SVG 保存至 Obsidian 资产目录，并在原文章光标处自动写入引用，全程无需跳出应用。
