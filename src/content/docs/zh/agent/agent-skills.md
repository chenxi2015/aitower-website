通用对话模型在面对特定工作流（例如等距图解、系统架构绘制、长文转脚本）时往往提示词冗长。**智能体技能库（Agent Skills）** 把这些沉淀好的工作流指令封装为可复用技能，按需加载给右侧 AI Agent。

## 技能来源与管理

在左侧停靠栏打开「智能体技能库」，可按来源过滤并检索全部已安装技能：

- **全部来源 / Built-in**：aitower 内置开箱即用的基础能力。
- **Agents / Codex / Claude**：兼容主流 Agent 技能目录，统一在一个面板中管理、搜索与安装。

支持按名称、描述或标签搜索技能，也可通过右上角「+ 安装技能」扩充自己的技能库。

## 常见技能示例

- `anatomy`：用精细的等距 SVG 图解复杂技术概念。
- `archify`：创建系统架构、工作流与数据流可视化。
- `diagram-design`：设计风格一致的流程图、对比图与架构图。
- `article-to-video` / `baikou-style-video`：将长文拆解并制作成口播短视频。

## 在对话中快速载入技能

在右侧 Agent 输入框中直接键入 `/` 即可唤出技能选择器，为当前任务挂载一个或多个专属技能，再输入你的具体需求即可开始执行。
