aitower 将 AI Agent 嵌入主窗口右侧，使其能够直接理解你正在处理的上下文，而不是孤立地在外部网页窗口反复复制粘贴。

## 上下文感知能力

Agent 会自动关联以下信息作为工作上下文：

- **当前文章**：你正在编辑的 Markdown 文件内容与光标位置。
- **关联笔记**：通过搜索或双链命中的 Vault 参考资料。
- **画板元素**：创作台当前激活的画板结构与布局状态。

## 高频协作动作

- **灵感发散**：结合不同目录中的历史笔记，交叉提炼反直觉观点或文章切入角。
- **结构化扩写**：依据零散要点梳理大纲、补全论证或生成对比矩阵。
- **跨笔记混合推理**：同时读取多篇文献笔记与 `.canvas` 节点，归纳统一结论。

## 多会话并发不串台

写作时你可以开一个会话让 AI 帮查资料或润色段落，同时在创作台开另一个会话让 Agent 起草架构图。后台会话静默流式生成，随时切换承接输出，互不干扰。
