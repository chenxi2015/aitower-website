## 第一步：打开你的 Obsidian Vault

启动 aitower 后，选择你现有的本地 Obsidian 笔记库目录即可开始工作。aitower 不会修改原有目录结构，也不会额外生成侵占空间的私有数据库。

## 第二步：熟悉三栏布局

![aitower 工作台三栏结构图](/docs/workbench-layout-zh.svg)

工作台由三个协同区域组成：

1. **左侧目录 / 抽屉**：在「笔记」模式下浏览 Vault 文件树；切换到「创作」模式时，提供画板列表、画板框架、画板模板、素材库、图片工具箱与智能体技能库。
2. **中间主工作区**：上方可随时在「笔记」与「创作」两个核心模块间切换，用于撰写 Markdown 长文或编辑无限手绘画板。
3. **右侧嵌入式 AI Agent 面板**：实时感知当前打开的文章、选中的笔记或画板元素，支持多会话并发运行。

## 第三步：跑通「写作 → 配图 → 插入」闭环

1. 在笔记工作台打开或新建一篇 Markdown 文章。
2. 当需要为某段文字配图时，在正文或右侧 Agent 面板中唤起配图需求（例如：*「根据当前段落起草一张手绘风格系统架构图」*）。
3. Agent 自动读取相关笔记上下文并在创作台起草画板元素，你可以直接在画布上拖拽微调配色与文案。
4. 点击导出并插入：高清 PNG/SVG 会存入 Obsidian 资产目录，同时在光标处自动写入 `![[图片名称.png]]` 引用。
