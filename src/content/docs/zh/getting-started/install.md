## 平台支持

| 平台 | 架构 / 安装包说明 |
| :--- | :--- |
| **macOS** | 支持 Apple Silicon (`arm64`) 与 Intel (`x64`) |
| **Windows** | 支持 Windows `x64` 安装包 |
| **Linux** | 支持 Linux `x64` 发行版包 |

你可以前往 [官网下载页](/download) 获取当前推荐版本，页面会自动识别你的操作系统与芯片架构；也可以直接访问 [aitower-releases](https://github.com/chenxi2015/aitower-releases/releases/latest) 查看所有历史构建与 SHA256 校验文件。

## 自动更新

桌面客户端内置自更新能力。首次安装后，当新版本发布时，应用会提示或自动完成更新，无需手动重复下载覆盖。

## 下一步

安装完成后，继续阅读 [5 分钟上手](/docs/getting-started/quick-start) 连接你的 Obsidian Vault。
